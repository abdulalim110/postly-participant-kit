# Instruksi Agent Postly Participant Kit

Instruksi lengkap repository berada di [`docs/AGENTS.md`](docs/AGENTS.md).
Setiap agent wajib membaca dan mengikuti file tersebut sebelum mengubah source
code atau dokumentasi. Aturannya berlaku untuk seluruh repository, bukan hanya
folder `docs/`.

Checklist pekerjaan tidak disimpan di file root ini. Gunakan plan aktif yang
ditunjuk oleh instructor di `docs/plans/` dan perbarui checklist serta log
eksekusinya pada file plan yang sama.

Bahasa kerja tidak wajib bahasa Inggris. Ikuti bahasa pengguna dan konteks
repository; istilah teknis, nama API, dan identifier kode boleh tetap memakai
bahasa yang paling jelas.
